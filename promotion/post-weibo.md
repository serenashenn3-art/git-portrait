## 版本二（长版）

GitHub 贡献者画像评测工具开源啦！🎉

有没有好奇过那些 GitHub 大神的画像长什么样？今天开源了一个小工具 GitPortrait，可以给任意 GitHub 贡献者生成有趣的画像评测！

✨ 主要功能：

1️⃣ 六维能力画像
工程实践、创新性、完成度、持续性、影响力、文档，全方位分析！

2️⃣ 江湖外号生成
Linus → 开源教父、企鹅守护者、分布式之神
Sindre → 模块大师、npm 活菩萨、全栈开源者
你 → 会是什么外号？

3️⃣ 投资价值评级
从 E 到 SS，像游戏装备一样直观！

4️⃣ 多语言支持
中英日韩等 8 种语言，一键切换！

5️⃣ 一键生成报告
支持导出完整画像文章，方便分享！
