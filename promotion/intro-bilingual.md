# GitPortrait 项目介绍

## 中文介绍

### 一句话介绍

GitPortrait 是一个有趣的 GitHub 贡献者画像评测工具，输入任意 GitHub 主页，自动生成六维能力画像、江湖外号和投资评级。

### 详细介绍

**GitPortrait** 让你的 GitHub 主页变成社交游戏！

只需输入一个 GitHub 用户名或主页 URL，就能获得：

- **📊 六维能力画像**：工程实践、创新性、完成度、持续性、影响力、文档
- **🎪 江湖外号**：开源教父、npm 活菩萨、模块大师...
- **💰 投资评级**：从 E 到 SS，像游戏装备一样直观
- **📝 一键生成报告**：支持中英日韩等 8 种语言

**技术亮点：**
- 纯前端实现，无需后端
- 预置数据 + 启发式分析
- 支持多语言国际化

**适合场景：**
- 快速了解一位贡献者的画像
- 发现值得关注的潜力创作者
- 给同事/朋友起个有趣的外号

**项目地址：** https://github.com/serenashenn3-art/git-portrait
**在线体验：** https://serenashenn3-art.github.io/git-portrait/

## English Introduction

### One-line Description

GitPortrait is a fun GitHub contributor portrait analyzer that generates 6-dimension portraits, nicknames, and investment ratings from any GitHub profile.

### Detailed Description

**GitPortrait** turns your GitHub profile into a social game!

Just enter a GitHub username or profile URL to get:

- **📊 6-Dimension Portrait**: Engineering, Innovation, Completion, Persistence, Influence, Documentation
- **🎪 Fun Nicknames**: "Open Source Godfather", "npm Bodhisattva", "Module Master"...
- **💰 Investment Rating**: E to SS tier, like game equipment ratings
- **📝 One-Click Report**: Supports 8 languages including English, Chinese, Japanese, Korean

**Technical Highlights:**
- Pure frontend, no backend required
- Pre-built data + heuristic analysis
- Multi-language internationalization

**Use Cases:**
- Quickly understand a contributor's profile
- Discover potential creators worth following
- Give colleagues/friends fun nicknames
