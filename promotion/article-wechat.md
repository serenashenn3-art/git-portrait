# 给 GitHub 贡献者一个有趣又有用的画像：GitPortrait 开源啦！

> 一个用启发式分析 + 真实数据拼接的趣味评测工具，让你的 GitHub 主页变成社交游戏。

![GitPortrait 主界面](assets/social-cover.jpg)

## 缘起：为什么要做这个？

你有没有好奇过：**那些 GitHub 大神的画像长什么样？**

我们经常会看到某位贡献者的主页，看到他的仓库数、Star 数、粉丝数，但很难快速形成整体印象。

于是我想：**能不能像星座、MBTI 一样，给每个 GitHub 贡献者一个有趣的画像？**

这就有了 **GitPortrait** —— 一个基于公开数据的六维画像评测工具。

---

## GitPortrait 能做什么？

### 🎭 生成六大维度画像

输入任意 GitHub 主页 URL，GitPortrait 会生成一份包含六个维度的能力画像：

| 维度 | 说明 |
|------|------|
| **工程实践** | README、测试、License 完整度 |
| **创新性** | 项目创意、关键词命中、描述多样性 |
| **完成度** | 所有项目的平均完成质量 |
| **持续性** | 近期活跃度、更新频率 |
| **影响力** | 粉丝数、Star 数、仓库影响力 |
| **文档** | 文档质量、双语支持 |

![六维雷达图](assets/weibo-cover.jpg)

### 🎪 生成江湖外号

每个画像都会生成 3-5 个有趣的江湖外号，比如：

- **Linus Torvalds** → 开源教父、企鹅守护者、分布式之神
- **Sindre Sorhus** → 模块大师、npm 活菩萨、全栈开源者
- **你** → 也许是什么意想不到的称号！

### 💰 投资价值评级

综合六维评分，给出从 **E 到 SS** 的评级：

- **SS（传说）**：真·值得 All in
- **S（史诗）**：非常值得关注
- **A（优秀）**：明确值得跟踪
- **B（良好）**：值得观察
- **C（潜力）**：保留观察
- ...

### 🌍 多语言支持

支持 **8 种语言**：
- 🇨🇳 简体中文
- 🇹🇼 繁體中文
- 🇺🇸 English
- 🇯🇵 日本語
- 🇰🇷 한국어
- 🇪🇸 Español
- 🇫🇷 Français
- 🇩🇪 Deutsch

### 📝 一键生成报告

点击"生成报告"，可以生成一份完整的画像总结文章，支持 8 种语言，方便分享！

## 怎么玩？

### 方式一：在线体验

访问：**https://serenashenn3-art.github.io/git-portrait/**


## 技术亮点

### 纯前端实现

- **无需后端**，纯 HTML/CSS/JavaScript
- **无 API 依赖**，使用预置数据 + 启发式分析
- **一键部署**，直接放到 GitHub Pages 就能用

### 启发式分析

- 性别推断（基于用户名关键词）
- 技术栈提取（从仓库语言/描述）
- 外号生成（综合画像特征）

### 多语言国际化

- JSON 翻译文件
- 一键切换语言
