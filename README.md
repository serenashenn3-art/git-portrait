## 简介

一个**有趣又有用**的 GitHub 贡献者社交画像评测工具：

- **趣味性**: 江湖外号 + 六维雷达 + 投资评级,像星座/MBTI 一样适合分享
- **实用性**: 项目质量评分 + 商业/技术价值分析 + 扩展可能性建议
- **社交属性**: 可复制外号集,一键分享给同事/朋友

## 功能特点

| 功能 | 说明 |
|------|------|
| **性别推断** | 启发式(用户名关键词 + 常见命名模式),纯娱乐 |
| **技术偏好** | 从仓库语言/描述提取技术栈、关注领域、常用工具 |
| **项目评分** | Stars/Commits/README/Tests/License/描述/时新 7 子项,满分 100 |
| **六维雷达** | 工程实践 · 创新性 · 完成度 · 持续性 · 影响力 · 文档 |
| **投资值** | 创新性×0.3 + 工程×0.2 + 完成度×0.2 + 持续性×0.2 + 影响力×0.1 |
| **商业 vs 技术价值** | 面向用户的产品化能力 vs 面向开发者的技术深度 |
| **外号生成** | 预置 + 动态规则,结合画像特征,给出"有理有据"的江湖名号 |

## 使用方法

1. 打开 `github-portrait.html`
2. 输入 GitHub 主页 URL 或用户名
3. 点击"开始画像" → 查看六维雷达 + 项目评分 + 外号 + 投资值
4. 点击外号可复制,分享给朋友

## 技术栈

- 纯前端 HTML/CSS/JavaScript
- ECharts 雷达图
- 无需后端,可直接部署到 GitHub Pages

## GitPortrait · GitHub Contributor Portrait

A **fun and useful** social portrait tool for GitHub contributors:

- **Fun**: Nicknames + 6-dimension radar + investment ratings, like zodiac/MBTI
- **Useful**: Project quality scores + commercial/technical value analysis
- **Social**: Shareable nickname collection

## Features

| Feature | Description |
|---------|-------------|
| **Gender Inference** | Heuristic (username keywords), for fun only |
| **Tech Preferences** | Extract tech stack, domains, tools from repos |
| **Project Scoring** | Stars/Commits/README/Tests/License/Description/Freshness, max 100 |
| **6-Dimension Radar** | Engineering · Innovation · Completion · Persistence · Influence · Documentation |
| **Investment Value** | Innovation×0.3 + Engineering×0.2 + Completion×0.2 + Persistence×0.2 + Influence×0.1 |

## Usage

1. Open `github-portrait.html`
2. Enter a GitHub profile URL or username
3. Click "Analyze" → View radar + scores + nicknames
4. Click nicknames to copy and share
